# Dinesh Singh Thakur — Portfolio

A simple responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Run it on your computer

1. Extract this ZIP file.
2. Open the `dinesh-portfolio-human` folder in VS Code.
3. Open `index.html` in your browser.
4. For automatic refresh while editing, use the Live Server extension in VS Code.

No Node.js or build tools are required.

## Check these details before publishing

- Confirm that the email address and GitHub profile are correct.
- Add your LinkedIn profile URL when you have the exact link.
- Add the correct repository or live-demo links for each project.
- Review the skills list and keep only the technologies you can explain in an interview.
- Update project descriptions so they match what you actually built.
- Add a resume PDF and a resume link if you want recruiters to download it.

## Publish with GitHub Pages

1. Create a GitHub repository for your portfolio.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The website address will appear in the Pages settings.

## Notes

The portfolio uses Google Fonts when an internet connection is available. If the fonts cannot load, the browser uses fallback fonts.
